# Auto Skill Picker

지금 하려는 작업을 AI Roasting 스킬 라이브러리의 큐레이션 카탈로그와 매칭해서, 바닥부터 다시 만들 필요 없이 검증된 외부 스킬을 찾아 붙여주는 스킬이다.

## 왜 이렇게 동작하는가

라이브러리 사이트(`https://airoasting-skill.vercel.app/?cat=pick`)는 검색 API가 없는 정적 큐레이션 페이지이고, 목록이 클라이언트 사이드 JS로 렌더링되기 때문에 `WebFetch`로는 빈 페이지("0 SKILLS")만 보인다. 실제 목록을 얻으려면 브라우저 도구로 렌더링해야 한다. 매번 브라우저를 여는 건 느리고 실패할 수도 있으므로, `references/catalog.json`에 26개 항목의 스냅샷(이름/저자/카테고리/설명/태그/stars/forks/github_url, 스크래핑 날짜 포함)을 내장해뒀다. 이 스냅샷을 기본으로 쓰고, 브라우저 도구가 있으면 최신 목록으로 가볍게 갱신을 시도한다 — 이렇게 하면 도구가 없는 환경에서도 항상 동작하고, 있는 환경에서는 최신성도 챙길 수 있다.

## 절차

### 1. 카탈로그 준비
`references/catalog.json`을 읽는다. 브라우저 도구(`mcp__Claude_Browser__*`)를 쓸 수 있는 세션이면 `https://airoasting-skill.vercel.app/?cat=pick`을 열어 `get_page_text`로 현재 목록을 한 번 확인해도 좋다 — 단, 이건 선택 사항이지 필수가 아니다. 실패하거나 도구가 없으면 그냥 스냅샷으로 진행하고, 사용자에게 "스냅샷 기준(YYYY-MM-DD)"이라고 짧게 알려준다.

### 2. 작업 맥락과 매칭
사용자가 지금 하려는 일(요청 문장, 다루는 파일 종류, 도메인)을 카탈로그의 `category`, `tags`, `description`과 비교한다. 딱 떨어지는 임베딩 검색이 아니라 상식적인 판단으로 충분하다 — 예를 들어 엑셀로 매장별 매출을 분석하는 작업이면 `투자·금융`이나 `리서치·인사이트` 카테고리 항목이, 발표 자료를 만드는 작업이면 `디자인` 카테고리가 후보가 된다.

상위 1~3개 후보를 추리되, **억지로 끼워 맞추지 않는다.** 카탈로그에 정말 맞는 게 없으면 "지금 카탈로그엔 이 작업에 맞는 게 없어 보인다"고 솔직하게 말하는 편이, 관련 없는 스킬을 추천하는 것보다 낫다.

### 3. 후보 제시
각 후보마다 다음을 간단히 보여준다:
- 이름과 한 줄 설명
- 왜 지금 작업에 맞는지 (카테고리/태그 근거)
- stars/forks (신뢰도 참고용 — 절대적 기준은 아님)
- GitHub 링크

### 4. 설치는 반드시 승인 후에만
사용자가 후보 중 하나를 골라 설치를 승인하기 전까지는 어떤 파일도 다운로드하거나 쓰지 않는다. 이건 임의 규칙이 아니라 세션의 안전 정책(파일 다운로드는 명시적 승인 필요)에 따른 것이므로 예외를 두지 않는다.

### 5. 설치
승인을 받으면:
1. 해당 GitHub 저장소를 확인해 `SKILL.md` 경로를 찾는다. 보통 저장소 루트, 또는 `skills/<name>/SKILL.md` 하위에 있다. `WebFetch`나 `raw.githubusercontent.com` 경로로 내용을 가져와도 되고, 저장소가 열려 있으면 직접 확인한다.
2. 사용자와 합의한 위치(기본은 이 프로젝트의 `.claude/skills/<skill-slug>/`)에 `SKILL.md`를 저장한다. 그 스킬이 참조하는 추가 리소스 파일(`references/`, `scripts/`, `assets/`)이 있으면 함께 가져온다.
3. 저장소가 단일 SKILL.md가 아니라 다중 에이전트/모노레포/복잡한 플러그인 구조(예: Everything Claude Code, Claude for Financial Services처럼 수십 개 파일로 구성된 경우)라면, 무리하게 자동으로 긁어오려 하지 말고 "이 저장소는 구조가 복잡해서 자동 설치 대신 GitHub에서 직접 필요한 부분만 골라 복사하는 걸 권장한다"고 사용자에게 안내한다.
4. 설치가 끝나면 어디에 무엇을 저장했는지, 그리고 그 스킬이 언제 트리거되는지(그 스킬의 description 요약) 간단히 알려준다.

## 참고
- `references/catalog.json` — Editor's Pick 26개 스냅샷. 이 파일이 카탈로그의 유일한 소스이니 새 후보를 지어내지 말고 반드시 이 안에서만 고른다.
